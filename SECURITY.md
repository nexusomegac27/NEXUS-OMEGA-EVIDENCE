# Security Policy

## Public-report boundary

Do not publish secrets, credentials, private keys, access tokens, cookies, personal identifiers, private paths, medical records, device raw data, private repository material, or unlicensed third-party full text.

If a potentially sensitive issue is discovered, stop publication and use the repository owner's private GitHub security-reporting channel after it has been enabled. Never place sensitive details in a public issue.

## Integrity boundary

SHA-256 detects byte differences within a bound view. It does not establish truth, authorship, authority, safety, or correctness. A local hash chain can be rewritten by an actor controlling the complete local history.

## Supported evidence version

Only schema version `1.0.0` and claim ceiling `C1` are accepted in the initial public lane.
