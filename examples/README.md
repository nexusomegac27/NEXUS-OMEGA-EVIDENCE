# Examples domain

Examples are non-authoritative demonstrations of repository contracts. They must never be treated as evidence merely because they validate.

- `a83/` — historical A83 example path.
- `artifact-handoff/` - non-authoritative examples for the GitHub handoff inbox.
- `artifact-rollout/` - non-authoritative examples for rollout preparation.
- `scientific-communication/` — communication profile examples.
- `r5/` — R5 examples paired with R5 schemas/validators.
