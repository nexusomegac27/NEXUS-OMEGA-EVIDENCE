## Repository Order Law V1 — persistent memory trigger

Repository order is a fundamental project invariant, not a cosmetic preference.

Before new work is written or integrated:

1. classify the artifact;
2. use the canonical owning directory from `README.md`;
3. place active research under `research/<phase>/<agent-or-topic>/`;
4. use the mirrored phase directories across `docs`, `schema`, `scripts`, `tests`, `validation`, and `examples` when research becomes implementation-grade;
5. preserve path-bound historical evidence in place;
6. update structure documentation and run the repository-structure validator whenever structure changes.

AXIOM and Cursor/PRAXIS carry this rule forward in every repository handoff. Ordinary placement mistakes are corrected without unnecessary global stops; provenance-breaking path changes require explicit migration and revalidation.
