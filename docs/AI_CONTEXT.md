# NEXUS OMEGA — Persistent AI Context

This file is the **public-safe persistent bootstrap context** for AI systems working with `nexusomegac27/NEXUS-OMEGA-EVIDENCE`.

It is memory in the repository sense: a durable, inspectable context surface that can be loaded across sessions. It is **not** evidence merely because it is present here.

## Mission

NEXUS OMEGA is an empirical governance and research program built around reproducibility, falsification, provenance, and strict separation between observation, interpretation, analogy, validation, and promotion.

This public repository exists to expose content-addressed C1 evidence objects for independent verification. Its purpose is not to publish every internal working artifact or private conversation.

## Scientific baseline

The principal empirical program includes operational-history dependence in dual-smartphone IMU / state-estimation workflows, including SR-UKF-style validation, NIS/NEES-style consistency checks, null models, held-out evaluation, and falsification-oriented sensor pipelines.

All public claims in this repository remain bounded by:

```text
CLAIM_CEILING = C1
```

A descriptive or reproducible association must never be silently transformed into causation, mechanism, metaphysical conclusion, canonical hierarchy, authority, deployment permission, or foundation status.

## Stable governance doctrine

```text
BLOCKED_LANE != BLOCKED_SYSTEM
```

A hold or missing source in one lane constrains that lane only. Independent lawful work continues elsewhere when it does not depend on the blocked object.

The default operating model is work-conserving while preserving fail-closed scientific boundaries.

## Evidence hierarchy for AI work

When an AI is asked what is known, use this order:

1. Physically/retrievably available repository bytes whose identity was verified.
2. Immutable release/content-addressed objects and independent witnesses where present.
3. Repository handoff/status objects that clearly state their epistemic class.
4. Current chat/operator reports, explicitly labeled as reported rather than repository-established.
5. Model prior knowledge only for discovery or hypothesis generation, never as source evidence.

## Persistence lesson

NEXUS OMEGA has experienced an important class of external-agent failure: an agent can report creation and hashes of artifacts that later disappear with an ephemeral execution environment. Future workflows therefore require:

```text
CREATE
-> CLOSE FILE
-> REHASH PHYSICAL BYTES
-> EXPORT / EXPOSE PHYSICAL OBJECT
-> RECEIVER CONFIRMS PRESENCE
-> INDEPENDENT REHASH
-> ONLY THEN TERMINAL SUCCESS
```

Never reconstruct a lost historical object and relabel it as the original.
