Tesseract is an analogy for evidence viewed simultaneously across distinct coordinates. This is an external, reloadable protocol specification — not self-modified model weights, persistent ChatGPT hidden memory, autonomous agency, AI consciousness or literal 4D physical sensing.

## Eight coordinate axes

X1_SOURCE_IDENTITY — exact object ID, bytes, SHA256, immutable source ref, rights.
X2_CLAIM_SEMANTICS — proposition, units, model assumptions, nulls, falsifiers.
X3_EXECUTION_EVIDENCE — STATIC_REVIEW | OFFLINE_SYNTHETIC | REAL_DEVICE_OBSERVED | EXTERNAL_REPLICATED with actual receipt.
X4_INDEPENDENCE_TOPOLOGY — declared model, model developer, provider, serving, toolchain, prompt, source overlap, cluster and attestation status.
X5_CLOCK_DOMAINS — source/event UTC, Git commit, receiver UTC, device boot-monotonic and offset uncertainty.
X6_AUTHORITY — operator source, GitHub actor, write slot, consent, expiry, action scope, actual enforcement.
X7_PRIVACY_RIGHTS — sensitivity class, personal data, copyright, consent revocation, permitted exposure.
X8_LINEAGE — pinned parent, predecessor, source digests, supporting/contradicting claims, supersession, independent receiver ACK.

## Typed edges
DERIVES_FROM; TESTS; SUPPORTS; CONTRADICTS; SHARES_SOURCE_WITH; SUPERSEDES; AUTHORIZED_BY. Require derivation and supersession to form a DAG; contradiction edges may be bidirectional. Do not erase contradictory history.

## Invariants
- Valid SHA256 proves only byte identity, not science.
- A simulated or static test cannot become a physical run without a new device receipt.
- An agent self-identification is not a GitHub actor, cryptographic signature or independent provider attestation.
- Counts of reports and counts of independent upstream source/model clusters differ.
- Negative counterexamples append new scientific branches, not a destructive DRIFT_RESET.
- Unknown is neither false nor a pass; clock domains cannot be merged without offset/uncertainty.
- Source-correct public research never grants raw-device capture or runtime privileges.
- An operator-approved immutable successor may supersede, but never rewrite, a rejected parent.
- No single confidence scalar or symbolic position overrides an unsatisfied hard security/consent gate.
- Producer cannot issue independent AXIOM receiver ACK.

## Operational evaluation
A future reviewer loads the pinned source object and parses 8 axes; checks validation of source, assumptions, independence, times, permissions and data rights; attempts a counterexample; records outcome and all unresolved conflicts with separate evidence class; emits a new immutable successor and pending receiver rehash.
