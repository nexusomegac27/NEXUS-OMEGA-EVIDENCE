## D.1 Kernsatz
Zwei Modelle, die dieselben ruhenden Trajektorien erklaeren, divergieren nach Anregung. Historische Uebereinstimmung ist keine Evidenz von Modellgleichheit.
Eigene Desk-Replikation: Ambiguitaetszeuge lambda = 1, b = 2 gegen lambda = 2, b = 1 an Beobachtung (0, 2); die datenbasierte LS-Schaetzung auf Ruhedaten zeigt formale Ranggleichheit, ohne die Kopplung aufzuloesen.

## D.2 Vertragsdefinition (AXIOM Paragraf 8, unverändert uebernommen)
- M(D): Menge der mit historischen Daten D vereinbarten Modelle.
- F(D, y) = { (M, x): M in M(D), x mit y vereinbar }. Eine Zielgroesse ist modelluebergreifend identifizierbar, wenn sie auf F(D, y) konstant ist.
- Zielunsicherheit W(D, y) = sup von P(M, x) minus inf von P(M, x) über F(D, y).
Eigene Wiederherstellung: auf Ruhedaten ist sup minus inf fuer die Zielgroesse strikt positiv; auf anregungsreichen Daten null im synthetischen Modell. Die Konstruktion verbindet die R45-4-Sandbox mit der Literatur zur Data Informativity und zur funktionalen Observabilitaet; sie ist methodische Integration etablierter Grundlagen, kein neu entdecktes Naturgesetz.

## D.3 Kollektivhypothese (falsifizierbar, NOT_RUN)
Experten verhalten sich wie konkurrierende Modelle: zwei Experten koennen dieselben bisherigen Beobachtungen erklaeren und in einer neuen Situation divergieren. Auswahlsatz: Beobachtungen so waehlen, dass konkurrierende Hypothesen divergieren; Unabhaengige Evidenz statt erzwungener Uebereinstimmung.
