**Falsification path:** controlled comparison holding organisational variables fixed while varying agent deployment and provenance regime.  
**If true →** E1-causality claim collapses.

### CH-2 · Incompatible metrics
The reported +220 % / +36 % / +40 % / +70 % rest on non-commensurable denominators or changing detection thresholds.  
**Falsification path:** obtain (or reconstruct) exact population definitions and time windows.  
**If true →** quantitative differentials lose evidential force.

### CH-3 · Provenance improves auditability but not productivity or availability
Strong hash/review/rollback chains raise the cost of change and may reduce net feature velocity.  
**Falsification path:** measured trade-off curves on controlled engineering tasks.  
**If true →** “provenance is always net-positive” is false; cost must be carried explicitly.

### CH-4 · Ring stabilises internal state while worsening accuracy against truth
A persistent bump can track a drifting internal representation better than a simple baseline while diverging further from external ground truth.  
**Falsification path:** head-to-head circular error against a known external phase under matched noise.  
**If true →** ring loses its engineering justification for orbit-phase applications.

### CH-5 · Global inhibition produces multi-peak or oscillatory regimes
Within realistic parameter ranges the network supports multiple bumps or limit-cycle behaviour.  
**Falsification path:** systematic parameter sweep + multi-peak injection tests (already required by PR65 HOLD).  
**If true →** uniqueness-of-bump claims are parameter-local only.

### CH-6 · Source-epoch and SGP4/TLE errors dominate short-horizon residual
Even at 120 s the dominant error source is the age or quality of the last element set, not filter-internal diffusion.  
**Falsification path:** error-budget decomposition with controlled epoch age.  
**If true →** investment priority shifts from attractor tuning to better / more frequent external witnesses.

### CH-7 · Unit ablation with retuning leaves the ring robust
After 40–60 % unit removal and modest parameter re-optimisation, persistence and correction capability remain within acceptable bounds.  
**Falsification path:** pre-registered ablation + retuning arms.  
**If true →** E2 monotonic-collapse story is false.

### CH-8 · Public page / CI success ≠ end-user functional truth
Retrievable HTML, green GitHub workflows, or static asset presence do not entail working MapLibre tiles, correct attribution, mobile behaviour, or GNSS/offline capability.  
**Falsification path:** independent B1/B2/B3 terminal proofs.  
**If true →** WWW_LIVE_VERIFIED_C1 remains unavailable.
