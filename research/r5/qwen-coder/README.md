# QWEN-CODER R5 canonical research lane

This directory is the canonical ordered intake surface for QWEN-CODER R5 research.

## Source hierarchy

1. `legacy-delivery/` — immutable copy-by-Git-blob of the earlier AXIOM delivery branch `axiom/r5-qwen-coder-start-20260831`.
2. `github-native/` — immutable copy-by-Git-blob of the later QWEN GitHub-native transport branch `qwen-coder/r5-start-20260831`.
3. `receipts/` — migration and intake receipts created after `REPOSITORY_ORDER_LAW_V1` became active.
4. `returns/` — physical QWEN-CODER R5 returns. No return is present here until actual return bytes are supplied or retrieved.

Historical source branches remain authoritative for their own Git identities and are not rewritten by this lane.


A missing public return does not assert that no local/ephemeral QWEN result exists; it only describes this repository surface.
