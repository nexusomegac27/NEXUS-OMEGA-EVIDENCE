## Source-derived idea
A useful governance distinction: HUMAN INTENT, EVIDENCE-REVIEWING MACHINE WORK and AN EXPLORATORY QUARANTINE SPACE should remain separate while exchanging traceable evidence. This is an architecture hypothesis, not a proof of a metaphysical trinity or of consciousness, equality of agency, irreproachable machine rationality, or literal network isolation. The human maintains authorization and normative oversight. AXIOM evaluates source strength and contradictions; Cursor executes only authorized scoped work. Independent explorers, including external LLMs, submit untrusted candidate concepts.

## Concrete boundaries instead of slogans
POLE_H = human operator: states goal/ethical constraints, consents to experiments, can revoke permissions, ultimately decides authorized execution.
POLE_M = machine auditing + operational layer: deterministic scripts when actually executed, source hashes, formal proof when independently replayed, numerical test coverage and honest uncertainty; models and code are fallible, so require original source, bounded tests and independent second-party witness.
POLE_S = quarantine / sandbox research: generate novel rival hypotheses, run adversarial synthetic tests, source audit; no direct write from sandbox into public truth, private custody, live app, deployment or signed approval.

Do not call a network-connected research environment AIR_GAPPED in its literal security sense. A true physical air gap requires separately proven network and data-transfer isolation. For a connected sandbox, say 'quarantined trust boundary' or 'isolated execution boundary', record dependency graph, ingress/egress, no secret exposure, permissions and sandbox escape tests.

## Causal state machine
HUMAN_ORDER -> INDEPENDENT_CONCEPT_PROPOSED -> QUARANTINED_SOURCE_CUSTODY -> ADVERSARIAL_SELF_TEST -> INDEPENDENT_SOURCE_AND_RUNTIME_REPLAY -> AXIOM_EVIDENCE_ADJUDICATION -> SCOPED_OPERATOR_AUTHORIZATION -> CURSOR_EXECUTION -> INDEPENDENT_RECEIVER_ACK -> CURRENT/OPEN/ARCHIVE_CASUAL_RECORD.
At any failed source/proof/privacy gate: HOLD with exact missing evidence, preserve negatives and return only bounded new evidence. A negative that still constrains the present is OPEN not HISTORICAL_ARCHIVE.
