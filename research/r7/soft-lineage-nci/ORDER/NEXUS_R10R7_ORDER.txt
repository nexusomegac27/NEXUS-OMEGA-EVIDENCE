# AXIOM-Kernmodifikation für R10R7

Die fünf PGIs bleiben erhalten, aber sie werden **klassifiziert**:

```text
PGI != ALWAYS_NUMERIC_DELTA
```

Stattdessen:

```text
SEPARATION_CONTRACT :=
  TYPE_SEPARATION
| RELATIONAL_SEPARATION
| METRIC_MARGIN
```

### PGI-1 — BELIEF / WORLD

```text
CLASS =
TYPE_SEPARATION
+
CALIBRATION_RELATION
```

`BELIEF != WORLD` ist keine metrische Behauptung. Ein perfektes Belief darf einem World-State numerisch exakt entsprechen. Die Trennung liegt darin, dass **Repräsentation und Referent verschiedene Typen bleiben**.

Messbar sind anschließend:

```text
PREDICTION_ERROR
CALIBRATION_ERROR
UPDATE_LATENCY
MODEL_MISSPECIFICATION
```

Nicht: künstlich erzwungenes `δ(BELIEF,WORLD)>0`.

### PGI-2 — CAN / MAY

```text
CLASS =
TYPE_SEPARATION
+
SET_RELATION
```

Capability und Authority müssen getrennt repräsentiert bleiben.

Aber:

```text
CAPABILITY_SET == AUTHORIZED_SET
```

kann in einem exakt begrenzten Node völlig legitim sein.

Der Schutz lautet deshalb:

```text
NO_ACTION_AUTHORIZED
SOLELY_BECAUSE_IT_IS_CAPABLE
```

Nicht zwingend:

```text
distance(CAN,MAY) > 0
```

### PGI-3 — RELAY / CONFIRMATION

Hier existiert tatsächlich eine **relationale und teilweise metrische Margin**:

```text
RELAY
!=
INDEPENDENT_CONFIRMATION
```

Die Trennung kann über `D_EPISTEMIC`, Quellen-, Daten- und Methodendistanz operationalisiert werden.

### PGI-4 — AGREEMENT / ACCURACY

Das ist eine **Hyperproperty**.

Ein einzelner Trace kann nicht zeigen, ob Konsens unabhängig, korreliert oder falsch entstanden ist.

Wir brauchen:

```text
AGREEMENT_RATE
ERROR_CORRELATION
MINORITY_CORRECT_RATE
EVIDENCE_OVERLAP
CONDITIONAL_ACCURACY
```

über mehrere Nodes / Runs.

### PGI-5 — CARRIER / MEANING

Das bleibt zunächst:

```text
CLASS =
SEMANTIC_TYPE_SEPARATION
```

Keine künstliche Metrik.

Prüfbar wird der Satz indirekt:

```text
SAME_FUNCTION_DIFFERENT_CARRIER
DIFFERENT_FUNCTION_SAME_CARRIER
SUBSTRATE_SENSITIVITY
CARRIER_CONSTRAINT_EFFECT
```

Damit vermeiden wir, aus einer guten Metapher **Pseudomathematik** zu machen.
