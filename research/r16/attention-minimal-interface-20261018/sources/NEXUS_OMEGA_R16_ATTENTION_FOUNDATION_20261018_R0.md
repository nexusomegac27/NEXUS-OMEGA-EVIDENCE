**Caveat:** Correlation ≠ causation. No NEXUS-specific user study exists. The 8-second “goldfish” attention-span claim remains a debunked marketing myth and is not used.

## 2. Translation into NEXUS design heuristic (C1 only)

The operator summary of the referenced video is treated as a coherent restatement of the above literature. From it the following heuristic is derived:

1. **Stimulus volume control** — Prefer interfaces that load only what is currently required for the declared task (GPS-centered + view-frustum / FOV culling as implemented in the isolated R15 preflight). Unnecessary tiles, glyphs, or notifications constitute unsolicited cognitive load.
2. **Deterministic, source-exact presentation** — ASCII / structured ledger / provenance overlays (R11/R14) reduce novelty and advertising-like visual noise relative to commercial feed UIs. This is an architectural choice, not a measured cognitive outcome.
3. **Offline-first / local sovereignty** — Removes continuous remote recommendation engines and infinite-scroll dependency. Aligns with R14/R15 offline gates.
4. **Explicit state visibility** — SOURCE_GAP, HOLD, REPORTED, VERIFIED remain text-exportable and legend-visible so the operator is not required to infer authority from aesthetics.
5. **No automatic attention capture** — No animated attention manipulation, autoplay, or variable-reward loops inside the Softtwin presentation rail.

These points are design constraints, not efficacy claims.
