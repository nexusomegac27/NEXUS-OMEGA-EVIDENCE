4. CVE-NVD-Check: Souveränitäts-Stack (Ubuntu / Ollama / SQLite-FTS5)
Das Artefakt nennt keine Versionen — der Check zeigt, dass es das muss. Der Stack ist 2026 mehrfach erfolgreich angegriffen worden, teils exakt gegen die Prinzipien, die NEXUS OMEGA verteidigt:
Ollama (Inferenz-Layer):
CVE-2026-7482 „Bleeding Llama" (CVSS 9.1): unauthentifizierter Heap-Out-of-Bounds-Read im GGUF-Loader; Leak von Prompts, Systemprompts, Env-Vars (API-Keys) über /api/create//api/push; Patch 0.17.1; ~300.000 exponierte Server weltweit beobachtet.  
CVE-2026-103663 (CVSS 9.4): Path Traversal in /api/pull → RCE als Root bei Docker-Deployments; gefixt in 0.35.0. 
CVE-2026-102697 (CVSS 8.5): Bypass des Agent-Mode-Bash-Tool-Approval (0.14.0–0.31.2) via Shell-Syntax-Anhängung — architektonisch direkt relevant für das Artefakt-Prinzip „keine unkontrollierte Agenten-Autonomie": Der Approval-Mechanismus selbst ist angegriffen worden. 
Weitere: CVE-2026-42248/42249 (Windows-Updater-RCE-Kette), CVE-2026-5757 (Heap-Leak Quantization), CVE-2026-15685 (DoS), CVE-2026-85180 (SSRF-Redirect, 8.7), CVE-2026-86289 (GGUF-Integer-Overflow).
SQLite/FTS5 (Ledger-Layer):
CVE-2026-11822 + CVE-2026-11824: Memory Corruption in FTS5 (fts5LeafSeek/fts5ChunkIterate) via präparierte Datenbanken; Code Execution möglich; betroffen < 3.53.2. Direkter Treffer auf die Manifest-/Witnessing-Schicht.  
Hinweis: Ein Teil der 2026er-SQLite-CVEs hat nach JFrog-Analyse fragwürdige Metadaten („LLM slop"-Verdacht) — Bei der Umsetzung echte Advisories (GitHub DB, NVD) gegen Vendor-Patches abgleichen. 
Operative Konsequenz für NEXUS OMEGA (Fail-Closed-konform):

Bind an Loopback, authentifizierender Reverse Proxy vor Port 11434, kein OLLAMA_HOST=0.0.0.0.
