# R44-4 scientific productivity: groundable metrics, not page-count theater

## Outcome vector (never a single unaccountable PASS)
- **Verified independent findings (VIF)**: exact claim-source-test triple supported by raw source or original method + independent replay and named comparator; not selfreported citations, GitHub mirror rehash or copy of already counted claim. Deduplicate by `SOURCE_CONTENT_SHA + ESTIMAND_ID + TEST_CASE_ID`. A single original source can support several genuine distinct observables; source-independent reviewer is tracked separately.
- **Executed discriminating controls (EDC)**: count positive/negative cases with actual log, code/data/runner hashes and exit; design-only zero. Report true negatives, false positives/false HOLDS and changed verdict relative to R44-3.
- **Source gap reduction (SGR)**: unresolved prior original bytes/version/license/trial-ID conflict actually closed with original documentation; one missing source replaced by a second copied opinion does not count.
- **Measured total resources (MTR)**: input/output tokens, price, tool calls, machine CPU incl children, wall monotonic, memory, actual bytes egress, retry and evaluator. Negative or unknown cost → denominator `UNKNOWN`, no valid superiority ratio.
- **Actor/auth independence (AAI)**: separate root-issued actor role/expiry/revocation, source/model/seed lineage and test exposure; advisory reviewer independence is not quorum authentication.
- **Duplication overhead (DUP)**: classify prose repeated from frozen parent vs new experimental data, dedup identical excerpts by source hash; raw evidence may legitimately repeat when required, but counted only once. Do not drop raw negatives to improve cosmetic ratio.
- **Risk and accuracy**: false admission, false rejection, holdout leakage, licensing/private info leak; no quality gain if safety degrades. Audit paper methods and subgroup uncertainty.

## Efficiency without shallow answers: a conditional Pareto rule
Only call A better than B if equivalent problem/ground-truth scope, quality/noncompensatory gate integrity not worse, and measured full resource cost lower OR new independently verified findings higher without increased cost beyond declared margin. Report uncertainty, no arbitrary fixed effect threshold. If one output is longer but contains no extra original evidence, it is inefficient. If a long methods supplement is needed for independent replay, preserve it.

## Report schema per researcher
`CLAIM_ID`, `NEW_VS_PARENT=TRUE/FALSE`, `SOURCE_ORIGINAL_SHA/Q`, `ESTIMAND`, `H0/H1`, `NEGATIVE`, `POSITIVE`, `CODE_SHA`, `DATA_SHA`, `RUN_EXIT`, `ACTOR_AUTH`, `INDEPENDENT_CROSSCHECK`, `EVIDENCE_UNIQUENESS_KEY`, `ACTUAL_TOTAL_COST/UNKNOWN`, `RELEVANT_GATES`, `SAFE_PUBLICATION`, `NEXT_VALUE_OF_INFORMATION`.
Report separately executive highlights and original complete method. More original research is the goal, not greater word count or more duplicate hash checklists.
