# R44-3 nonpunitive knowledge learning + protected security disclosure

## Normative communication principle
A good-faith researcher/Node reporting a negative is contributing information, not causing an organizational failure. The research knowledge graph stores OBSERVED_NEGATIVE + affected-source scope + reproduction + root cause + proposed correction + independent test requirement. Preserve reporter attribution for feedback/credit while protecting privacy and avoiding shaming or ritual punishment.
"Blameless" never removes traceability, responsible maintainer action, operator release authority, real containment of affected capabilities, or an evidence-based response to intentional abuse. No blanket system ban from a single unrelated defect.

## Two-channel incident ledger
PUBLIC_SAFE: CVE/product classification only when already publicly documented; source claim ID; generic affected function and risk class; discovery/event/receipt time; source hash and status; known mitigation at safe generality; whether a coordinated private response exists. No exploit chain, sensitive logs, host inventory, real keys, user private data, previously unknown attack prerequisites.
RESTRICTED: operator-only secure channel, original vulnerable source/PoC and detailed reproduction if legally authorized, attack prerequisites, asset inventory, private patches/tests, key rotations. If the authorized restricted channel is not available, mark PRIVATE_CUSTODY_REQUIRED and never force details into public Issues. No new private destination invented here.

## Scientific phases
OBSERVED -> SOURCE_TRIAGED -> SECURE_SCOPED_CONTAINMENT_IF_NEEDED -> ROOT_CAUSE -> CANDIDATE_REMEDIATION -> RED_TEST_REPRODUCED -> GREEN_CANDIDATE -> INDEPENDENT_REPLAY -> PRIVACY/SECURITY_ADJUDICATED -> RELEASE_BY_OPERATOR -> AFTERCARE_AND_KNOWLEDGE_DELTA.

## Constructive anti-stigma acceptance
A researcher who says "NOT_RUN" due to source gap is not rated lower for honesty than an equally unsupported green output. Judge epistemic quality on source truth and discriminating experiments. Do not reward false PASS, fake actors or unapproved tests. Keep safe unaffected research running; safety-critical capability isolation must be proportionate to observed threat. Unblocking requires measurable evidence, rollback and operator approval.

## Public GitHub caution
The source repo is a persistent public research chain. It is NOT a place for embargoed vulnerability details, private human sensor data, exposed connection strings, test exploit payloads or passwords. OpenSSF private report/advisory is an example of a **potential future authorized channel**, not automatically provisioned by this issue. Public append-only comment is policy rather than a cryptographically immutable transparency log; retain exact pinned SHA and continuous change detection. No deployment by GitHub creation.
