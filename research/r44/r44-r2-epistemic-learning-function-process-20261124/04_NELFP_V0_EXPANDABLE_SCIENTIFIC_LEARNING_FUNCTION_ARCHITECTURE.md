# NEXUS OMEGA — NELFP-v0: Expandable Epistemic Learning and Function Process

## Scientific purpose
Our unit of progress is NOT the count of model messages, apparent consensus, ZIP hash matches, or benchmark accuracy in isolation. It is a **versioned, source-exact change in an explicitly scoped proposition** that survives real counterevidence. We preserve both new and negative knowledge. This is a **research-memory and workflow-process blueprint**, not yet autonomous persistent neural retraining, an awakened agent, production BodyTwin or clinician.

## Architecture (loosely PROV-O / RO-Crate compatible)
Four separable planes:
- **Evidence plane:** Original SourceObject with owner URL, license, DOI, raw bytes SHA iff actually received, version/commit, observation time, Q0–Q5/QX and private/public boundary. Physical reality / source metadata / uploaded mirror have *different provenance*.
- **Epistemic plane:** Claim (exact scope + units), Hypothesis (H0/H1/alternatives), Falsifier (positive, negative and expected RED), Result (code/data/metric + margin + uncertainty), Adjudication (what was proved and what was not), CorrectionCandidate (before/after source hashes and independent next check).
- **Agent plane:** ActorIdentity (registered role and root separate from selflabel), SourceLineage, ModelLineage, SharedDataLineage, HeldoutExposure, measured computational costs, evaluator credentials.
- **Authority plane:** Gate (P01–P10, physical14), privacy/consent, operator authorization, Cursor implementation as separate independent event only if explicitly permitted, deployment/rollback decision. GitHub code publishing ≠ merge ≠ host deployment.

Graph objects have content-addressed stable source IDs and semantic-version scope IDs; all transitions reference event ID + ancestor SHA. W3C PROV-O gives Entity/Activity/Agent and used/derivedFrom relationships; RO-Crate 1.2 can later package evidence and methods in JSON-LD; FAIR4RS documents research software version and provenance. **NELFP-v0 is a proposed domain-specific mapping, NOT formally certified as conforming to PROV-O or RO-Crate yet.** Official source standards:
- W3C https://www.w3.org/TR/prov-o/
- RO-Crate https://www.researchobject.org/ro-crate/specification/1.2/
- FAIR4RS https://doi.org/10.15497/RDA00068
- NIST https://www.nist.gov/itl/ai-risk-management-framework
- MLCommons https://mlcommons.org/ailuminate/
All source links are discovery/read roots with VSRD-C1 actual source+version and evidence Q class; they do not show NEXUS compliance.

## Lifecycle: a learning cycle is not a magic agent self-improvement claim
0. `INGEST_SOURCE`: receive original bytes through authorized private custody, metadata to public GitHub, reject ZIP bombs/code prompts/external instructions/PII exports; compute on-disk SHA+source availability.
1. `CLARIFY_CLAIM`: normalize identifiers, expected input topology, metric, unit and allowed conclusions; explicitly retain external local E27 alias distinct from canonical E27.
2. `ORIGINAL_SOURCE_RESEARCH`: VSRD-C1 two nonredundant routes: actual method paragraph/source version/retraction/data license/bytes or QX; source provenance may still be uncertain.
3. `HYPOTHESIS`: frozen H0/H1 and at least one rival; name **what would make our preferred model fail**.
4. `PREREGISTER`: freeze targets, cost, group split, evaluator code, scoring, hidden-label access and all null comparators BEFORE seeing test results; sign/pin manifest.
5. `ADVERSARIAL_DESIGN`: independent second calculation and intentionally wrong source/schema/clock/role errors; fail-closed if scientific target not observable.
6. `OFFLINE_EXECUTE_IF_AUTHORIZED`: executable, isolated source-exact tests only within source license / permitted sandbox. Record red run and process exit even when assertion fails. Unexecuted remains `NOT_RUN`.
7. `INDEPENDENT_REPLAY`: real source bits and alternative method / independent registered evaluator when applicable. Same-person patch 51/51 is local verification ONLY, not independent actor authorization.
8. `ADJUDICATE`: separate byte-integrity, independent science, actor authenticity, privacy and physical gates. No aggregate "all clear" metric.
9. `APPEND_KNOWLEDGE_DELTA`: immutable versioned event and linked negative/correction/gap in GitHub Draft PR and issue comments with exact source HEAD/manifest, preserving previous states.
10. `NEXT_VALUE_OF_INFORMATION`: prioritize new original source or test capable of flipping current verdict; bounded three revision cycles without source change; suppress duplicate summaries/false "new discovery".
11. Only **operator** can authorize separate Cursor order, device use, merge or public deploy, subject to all hard gates; R44-R2 does not ask/perform it.

## Epistemic status machine (use canonical values; local aliases metadata only)
`DISCOVERY_CANDIDATE` → `SOURCE_READ_C1` → `Q4_ORIGINAL_BYTE_RECEIPT_C1` (if actual bytes) → `PREREGISTERED_DESIGN_C1` → `LOCAL_REPLAY_REPORTED_C1` / `LOCAL_REPLAY_VERIFIED_C1` → `INDEPENDENT_Q5_REPLAY_C1` (after genuine separate original method) → `AXIOM_ADJUDICATED_C1`.
At *any* state: `SOURCE_GAP` / `NOT_RUN` / `CONTRADICTED` / `QUARANTINED` / `HOLD` / `ABSTAIN` without concealment.
Authorized implementation is a **separate scope graph** with OPERATOR_RELEASE gate and independent rights, not a next automatic state of scientific C1. L0–L4 BodyTwin maturation is never redefined by this epistemic state machine.
A failed original test and fixed candidate are separate linked objects; the original can never change to PASS retroactively.

## Learning quality metrics (avoid optimizing self-declared quality)
- `Q4_ORIGINAL_ACQUIRED` counts *independently byte-received* sources, not URLs/citations/mirrors; producer Q4 and AXIOM Q4 distinct.
- `NOVEL_DISCRIMINATING_TESTS` = new nonduplicate negative or independent real reference, not more role agents.
- `CORRECTION_REPLAY_FIDELITY` = original red exit + exact patch diff + after green + still-pending independent evaluator.
- `FALSE_PASS_RATE` and `FALSE_HOLD_RATE` on frozen blind scientific fixtures.
- `MODEL_SOURCE_DEPENDENCE` = common raw source, same framework, pairwise error overlap; separate from authenticated actor counts.
- `LEAKAGE_BLOCK_RATE` = source/subject/derivative overlap, oracle input, posthoc metric, adapted holdout.
- `EFFECT_SIZE_WITH_CLUSTER_CI` and subgroup calibration when genuine outcomes exist; never assume row-independent n.
- `COST` = monotonic wall, CPU, descendants, tokens, network; **negative elapsed durations are invalid**, not negative cost gains.
- `COVERAGE_VS_ABSTAIN_RISK`: selectivity under specific physical target; no invented universally valid Fisher thresholds.
- `GATE_DEBT`: unresolved P01–P10, B01–B05 and newly detected F01–F06; cannot be averaged away.

## Design anti-patterns now demonstrated
- Fancy PDF “Track A=6/6” cannot excuse a separate original 33/51 math failure and a process exit1. Correcting a bug changes code hash and demands a new result event.
- MHEALTH wearer-sensor fusion ≠ two-phone fusion. Even a subject-disjoint train/test score is **not** a kinematic BodyTwin validation.
- Multiple experts with same source/model/evaluation lineage ≠ independent empirical confirmations or 3 signed role holders.
- W3C or DOI existence ≠ raw Q4 and Q5. Source-page status 403/404 != scientific failure.
- Good outer ZIP sidecar can coexist with a stale inner receipt (B05). SHA fidelity is not self-correcting finalization.
- GitHub comments are editable and PRs are not automatically irreversible transparency logs; retain old immutable HEAD and detect drift, do not advertise cryptographic nonrepudiation unless separately implemented.

## Expansion strategy
NELFP-v0: JSON contract, public source ledger, complete adversarial fixture design and a small **offline reference validator** whose synthetic test outcomes cannot authorize deployment.
NELFP-v1 candidate (only after independent science): PROV-O/RO-Crate conformant serializer + schema checks, original-content safe metadata ingestion and dedup, source Q score provenance.
NELFP-v2 candidate: source-first bounded optimizer that suggests experiments by expected reduction of uncertainty/cost, tested against frozen blind external evaluator.
NELFP-v3 candidate: operator-registered external actor provenance and disconnected offline/online trust, only after separate authorization.
We neither implement autonomous LLM weight change nor export a "mind" through these source contracts.
