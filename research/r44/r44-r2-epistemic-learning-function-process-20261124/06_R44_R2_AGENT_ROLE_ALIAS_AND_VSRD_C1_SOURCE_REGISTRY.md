## Mandatory original-source research recipe
1. Canonical `CLAIM_ID` + literal source/title + intended scientific transfer scope.
2. Source #1 actual original authority first, immutable DOI/commit or explicit `QX`, version/checked_at and original bytes hash only when actually read.
3. Source #2 genuinely different authority/method or independent original data, not same mirror/agent paraphrase; conflicting source assertions remain side-by-side.
4. Dataset topology record: source phones n distinct, participants n, sessions, mounts, timebases, label reference, consent, data rights; **rows/windows are not participants**.
5. SCIENCE evidence: H0/H1/pre-frozen test, original runner SHA, raw counts+unit sanity, loss, negative mutant, exit code, blind group split and actual cost.
6. Actor evidence separate: provider/model family/source sharing, role signature rooted in operator registry, evaluator source, holdout exposure and challenge; `n_eff=1` advisory when all self-declared.
7. Govern result: descriptive C1 source read or local math result, explicitly prohibit clinical/physical promotion and no user authority for new Cursor handoff.
