## New scientific quality thresholds (design, not empirical universal constants)
Scientific closure must cover: identical operator-supplied original bytes and first-party source versions; source semantic scope exact; two nonredundant sources for substantive claims; pre-frozen scoring and group split; provenance of every test; red & green counters with actual exit codes; independent actor/auth model; valid count/time; relevant sensor topology and independent reference; body privacy and separate operator physical authority. **One missing hard gate cannot be outweighed by many healthy hashes or messages.**

## New time, provenance and causal invariants
- Source occurrence time, network fetch time, disk acquisition time, authored created_at, GitHub commit event time and actor ACK timestamps are distinct; no retroactive rewrite.
- All evaluator code/score/hash, labels and source version MUST be frozen pre-test for an actual prospective result.
- A `RUN` node records process exit and all failing cases even on `AssertionError`; a validator must not inspect only final stdout or exit0 assumption.
- `CORRECTION_CANDIDATE` requires original and proposed hash, negative retained and new positive receipt. Independent reexecution Q5 separately authorized and not inferred from self-fix.
- Source license verified for source *dataset*, not merely repository code license.
- Event selfhash + GitHub immutable commit ref is a **drift-detection method**, not a tamper-proof transparency ledger unless separately audited.

## Next falsification before promoting reference validator
The 15-case static validator is deliberately small and typed. It does NOT assert completeness, vulnerability resistance, semantic source certainty, identity authentication, physical truth or schema compliance with official PROV-O. Next evaluate adversarial missing fields, malformed JSON, strings in numeric count fields, adversarial NaN/Infinity, archive path traversal, self-referential hash cycles, multi-actor same-origin, multi-source one DOI alias and multi-measurement cost parity. These are design candidates awaiting actual source/test execution. A green toy gate is not a security guarantee.
