## 2. Scientific architecture R44-R2—NEXUS Epistemic Learning and Function Process (NELFP-v0)

### Core graph entities (PROV-compatible with version-bound GitHub anchors)
`SourceObject`: actual typed original source/license/DOI/URL/bytes/SHA or NOT_OBTAINED, fetched_at, redirects and source Q-level.
`ActorIdentity`: self-declared label vs operator-registered signing root/role/validity, separate source/model/data genealogy.
`Claim`: literal scoped proposition/target metric and units, confidence and claim ceiling; immutable claim id/version.
`Hypothesis`: H0/H1/competitors, measurable estimand, harm/risk, alternative.

`AuthorityDecision`: separate operator release/rollback decision, not inferred from evidence or a GitHub draft.

`WAS_DERIVED_FROM`, `USED`, `GENERATED_BY`, `HYPOTHESIZES`, `TESTS`, `CHALLENGES`, `REPRODUCES`, `REFUTES`, `CORRECTS`, `REQUIRES`, `BLOCKED_BY`, `AUTHORIZED_BY`, `SUPERSEDES_SCOPE_ONLY`, `NO_INDEPENDENT_ORIGIN`.
