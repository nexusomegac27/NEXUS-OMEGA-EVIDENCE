# Artifact handoff inbox

```text
OBJECT = NEXUS_OMEGA_RESEARCH_PIPELINE_ARTIFACT_HANDOFF_V1
PROTOCOL = INBOX_VALIDATE_BIND_RELAY_ACK_V1
STATE = ACTIVE_C1_TRANSPORT_INFRASTRUCTURE
CLAIM_CEILING = C0_EXPLORATORY / C1_DESCRIPTIVE
```

This directory is the canonical GitHub handoff surface for external agent and
Cursor returns that should move without routine Operator mediation.

## Stages

```text
inbox/     submitted handoff envelopes
bound/     generated byte-binding receipts
relay/     generated relay packets for the next agent/context
ack/       generated acknowledgement receipts and workflow-event ledgers
```

The GitHub workflow `validate-artifact-handoff` runs the same validator as local
operators:

```bash
python scripts/artifact_handoff.py --root . validate
python scripts/artifact_handoff.py --root . process --output _artifact_handoff_out
```

Successful processing means structure, byte references, receipts and ledgers
are bound. It does not mean scientific validation, merge authority, integration
authority, claim promotion, foundation promotion or deployment authority.

## Submission rule

Create exactly one directory per return under:

```text
research/pipeline/handoff/inbox/<HANDOFF_ID>/handoff.json
```

The envelope must reference:

- returned payload bytes;
- Entry Receipt;
- Exit Receipt;
- File-Event Ledger;
- Workflow-Event Ledger;
- token and continuation status;
- explicit Authority-Gate status.

Missing or inconsistent material fails closed.
