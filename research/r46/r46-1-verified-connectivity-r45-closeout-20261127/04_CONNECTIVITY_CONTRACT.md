# Verified connectivity, proposed contract V1
Reachability != authenticity != authorization != semantic compatibility != freshness != successful effect != scientific truth.
Per-edge receipt: route_id, origin/destination stable source identity, actual source commit/hash, transport and auth scope, request/correlation ID, exact response bytes/hash, schema and version, independent checker/observer, clock domain and uncertainty, data class, claim scope, permitted next action, blocker, terminal outcome. No private payload in public receipt. Source-only readback must not imply write capability. If no approved credentials/route, HOLD_SCOPE, never expand. 
Separate route health from data validity, and current status from last known verified; a 304 can be a connectivity witness but not a fresh measurement. Exact monotonic ns decimal strings, reject leading zeros except "0", enforce bounded integer range consistent with Android Long, parse strict JSON duplicate detection, no Boolean/string/nonfinite sensor values, vector dimensionality and exact units tied to sensor_type, valid lowercase 64 hex (or explicitly versioned canonical policy), digest verified against actual bytes not syntax only; require schema and valid time ordering before freshness. Recursively reconstruct public approved typed aggregate fields, reject arbitrary objects/nested raw identifiers. Unknown, unsupported and malformed fields -> quarantine. No actual personal/physical data on public path. 
Status mapping not one-to-one: raw COMMITTED = LOCAL_COMMIT_OBSERVED, not VERIFIED_EFFECT until independent readback; VERIFIED_MOCK = verified synthetic effect only; ABSENT = scoped local observation, not guaranteed external no-effect; DUPLICATE = exact prior request lookup only, no new effect or authority; CONFLICT = hold/quarantine; HOLD_MISMATCH = HOLD_INTEGRITY; DENIED = only proven rejected before effect; lock exception with independently demonstrated no commit -> no-effect or retryable denied as explicitly scoped, ambiguous outcome -> UNKNOWN; UNKNOWN never auto retry nonidempotent. Validate schema before duplicate branch (bool duplicate, NaN time duplicate, None body exception reproduced). Bind request, principal, payload, action, cost, nonce, epoch, current policy, deadline, resource fence; separate read-only historical receipt retrieval permission. Preserve STOP outside snapshot. Local SQLite transaction does not imply distributed atomicity. 
Connectors and nodes: explicit existing capability registry, least privilege and finite lease; no hidden live fallback. Raw, canonical, numeric identities separate. Cross-device clocks independent; fit offset/drift only with reference evidence and uncertainty. Scientific target observability and numerical conditioning stay explicit; NIS not ground truth, NEES needs independent reference. DREAM (L2) may generate hypotheses within lease, cannot actuate; B1 source/legibility, B2 claim fidelity/nonvacuity, B3 fresh real authority, B4a observer ready, B4b actual independent readback. No compensation across barriers. R46-1 only local synthetic exercise, not deployment.
