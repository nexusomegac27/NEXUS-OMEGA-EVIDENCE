## Core result

The proposed NEXUS agent is **not** a model and is **not** an agent framework.

```text
NEXUS_IDENTITY
!= MODEL
!= AGENT_FRAMEWORK
!= INFERENCE_RUNTIME
!= PROVIDER
!= HOST
```

The continuity body is defined as the portable combination of:

```text
CANONICAL FUNDUS
+ CONTENT-ADDRESSED EVIDENCE
+ PROVENANCE
+ POLICY
+ VALIDATION HISTORY
+ CAPABILITY REGISTRY
+ AUTHORIZATION STATE
+ RECOVERY CHECKPOINTS
```

Models, frameworks, runtimes and infrastructure are adapters around that body.

## Operating invariant

## R1 scientific corrections

Three useful R1 ideas are retained after narrowing their scientific scope:

1. **Self-explanation/Feynman-style explanation** is treated as a review heuristic, not a scientific validator.
2. **Mind/graph mapping** is treated as a structuring heuristic. Claims about activating “both hemispheres” are not retained.
3. **Zettelkasten-style atomic linked notes** are treated as an information-architecture pattern, not evidence of claim validity.

## Workspace independence finding

The two bundled Grok workspace ZIPs are nearly the same snapshot, not two independent evidence
sources. Their common scientific/code content is byte-identical except for one status file;
one workspace also contains one additional image. They must therefore be treated as a single
dependency cluster for evidence accounting.
