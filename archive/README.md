# Archive domain

`archive/` is for retired or superseded material whose path is **not** itself part of an immutable evidence/provenance binding.

Do not move path-bound historical artifacts here merely for visual cleanliness. In particular, `docs/phase2/` and the A83 compatibility paths remain where their published binding expects them.

Any future archival migration should include a mapping/receipt that records predecessor path, successor path, content identity, reason, and validation status.
